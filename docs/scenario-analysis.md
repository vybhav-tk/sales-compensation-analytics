# Scenario and Sensitivity Analysis

## Purpose

Scenario analysis tests how compensation cost and participant outcomes change when plan or performance assumptions change.

## Example Scenario Levers

- Target increases or decreases
- Accelerator threshold changes
- Commission or incentive-rate changes
- Payout-cap changes
- Measure-weight changes
- Stronger or weaker simulated performance

## Comparison Metrics

Each scenario can be compared with the base case using:

- Total payout
- Average payout
- Median payout
- Number and percentage of participants affected
- Attainment distribution
- Payout distribution
- Number of participants reaching accelerators or caps
- Compensation-cost concentration

## Analytical Principle

The objective is not to prescribe a compensation-plan change from synthetic data. It is to demonstrate how an analyst can quantify tradeoffs among plan cost, differentiation, attainability, and participant outcomes before stakeholders make a decision.
